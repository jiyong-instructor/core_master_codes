# 01-01 오늘 배운 내용 정리

안녕하세요 여러분! 오늘은 자바스크립트에서 데이터를 변수에 담는 방법과, 문장 안에 데이터를 편하게 넣는 템플릿 리터럴을 배웠습니다.

자바스크립트도 처음에는 낯설 수 있지만, **이름을 붙인 상자에 값을 담아 사용한다**고 생각하면 어렵지 않습니다!

## 1. 자바스크립트 영역

자바스크립트는 HTML 안의 `<script>` 태그에 작성하거나, 별도의 `.js` 파일을 만들어 연결해서 사용할 수 있습니다.

```html
<script>
  console.log("자바스크립트 영역입니다")
</script>
```

`console.log()`는 값이 잘 들어있는지 브라우저 개발자 도구의 콘솔에서 확인할 때 사용합니다.

## 2. 변수 선언 키워드

`01-data.js`에서 `var`, `let`, `const`를 각각 비교해봤습니다.

```js
var 옛날방식 = "var는 예전부터 쓰던 변수 선언 방식입니다"
let 바뀔수있는값 = "나중에 값이 바뀔 수 있습니다"
const 바뀌지않는값 = "다시 대입하지 않을 값에 사용합니다"
```

- `var`: 예전 방식의 변수 선언입니다. 지금은 보통 잘 쓰지 않습니다.
- `const`: 같은 변수에 새로운 값을 다시 넣지 않을 때 사용
- `let`: 나중에 값이 바뀔 수 있을 때 사용

기본적으로 `const`를 먼저 사용하고, 값 자체를 다시 넣어야 할 때 `let`을 사용하면 됩니다. `var`는 범위가 헷갈릴 수 있어서 실무에서는 거의 사용하지 않습니다.

## 3. 데이터 종류

자바스크립트에는 여러 가지 데이터 타입이 있습니다.

- 문자열: `"안녕하세요"`
- 숫자: `10`
- 참거짓: `true`, `false`
- 빈 값: `null`
- 아직 값이 없는 상태: `undefined`

이런 기본 타입들을 조합해서 더 큰 데이터를 만들 수 있습니다.

## 4. 배열과 push

배열은 여러 값을 순서대로 담을 수 있는 데이터입니다.

```js
const 쇼핑리스트 = ["컴퓨터", "핸드폰", "티켓"]
쇼핑리스트.push("시계")
```

`push()`는 배열의 마지막에 새로운 값을 추가합니다. `const`로 만든 배열도 배열 안의 값을 추가하거나 수정할 수 있습니다. 다만 `쇼핑리스트 = 다른배열`처럼 변수 자체에 새 값을 다시 넣을 수는 없습니다.

## 5. 객체

객체는 이름표와 값이 한 쌍으로 묶인 데이터입니다.

```js
const 학생 = {
  이름: "철수",
  나이: 12,
  취미: "축구",
}
```

- 객체는 `이름: 값` 형태로 정보를 저장합니다.
- `학생.이름`처럼 점 표기법으로 값을 꺼낼 수 있습니다.
- 배열 안에 객체를 넣으면 여러 사람의 정보를 한 번에 관리하기 쉽습니다.

## 6. 템플릿 리터럴

`02-template-literal.html`에서는 여러 데이터가 들어간 문장을 만들어봤습니다.

```js
const 이름 = "길동"
const 나이 = 20
const 학교 = "강동캠퍼스"

console.log(`${이름}는 ${나이}살 이고 ${학교}에 다니고 있습니다.`)
```

템플릿 리터럴은 작은따옴표가 아니라 백틱(`)으로 감싸고, 값이 들어갈 자리에는 `${변수이름}`을 작성합니다. 문자열을 `+`로 여러 번 이어 붙이는 것보다 읽기 편하고, 줄바꿈도 그대로 표현할 수 있습니다.

## 오늘의 핵심

1. 변수는 데이터에 이름을 붙여 보관하는 상자와 같습니다.
2. 기본적으로 `const`, 값 자체를 바꿔야 한다면 `let`을 사용합니다.
3. `var`는 예전 방식이라 지금은 주의해서 봐야 합니다.
4. 자바스크립트에는 문자열, 숫자, 참거짓, `null`, `undefined` 같은 기본 데이터가 있습니다.
5. 배열은 여러 데이터를 순서대로 담고, 객체는 이름과 값을 묶어서 저장합니다.
6. 문장 안에 변수를 넣을 때는 템플릿 리터럴이 편리합니다.
