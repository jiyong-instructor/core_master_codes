# 02-02 오늘 배운 내용 정리

안녕하세요 여러분! 오늘은 조건에 따라 다른 코드를 실행하고, 배열을 반복하거나 골라내는 방법을 배웠습니다. 마지막에는 이 내용을 연결해서 친구 목록과 상세 페이지까지 만들어봤습니다.

오늘의 핵심 흐름은 **조건 판단하기 → 배열 가공하기 → HTML 만들기 → 화면과 상세 페이지에 연결하기**입니다!

## 1. if, 삼항 연산자, switch

`01-if-and-switch.js`에서 조건에 따라 다른 코드를 실행해봤습니다.

```js
if (공부점수 >= 60) {
  console.log("합격")
} else {
  console.log("불합격")
}

const 결과 = 공부점수 >= 60 ? "합격" : "불합격"
```

- `if`: 조건이 참일 때 실행
- `else`: 앞의 조건이 거짓일 때 실행
- 삼항 연산자: 간단한 조건의 결과를 한 줄로 만들 때 사용
- `switch`: 하나의 값을 여러 `case`와 비교할 때 사용
- `break`: 일치한 case를 실행한 뒤 switch문을 종료
- `default`: 일치하는 case가 없을 때 실행

## 2. map으로 배열 반복하기

`02-array-map.js`에서 친구 이름을 하나씩 꺼내 새로운 배열을 만들었습니다.

```js
const 친구들 = ["철수", "영희", "훈이"]

const 우리반 = 친구들.map((나의친구, index) => {
  return `${나의친구} 어린이는 ${index}번째에 들어있어요!`
})
```

`map()`은 배열의 모든 값을 한 번씩 확인하고, `return`한 결과를 모아 **새로운 배열**을 만들어줍니다. `index`는 현재 값이 들어있는 순서이며 0부터 시작합니다.

## 3. 배열로 반복 태그 만들기

`02-repeat-tag.html`에서는 `map()`으로 친구 수만큼 HTML을 만들었습니다.

```js
const 내가만든HTML = 친구들.map((el, index) => `
  <h1>${el}는 ${index}번째</h1>
`).join("")

document.getElementById("태그보여주는곳2").innerHTML = 내가만든HTML
```

`map()`의 결과는 배열이기 때문에, `join("")`으로 배열의 내용을 하나의 문자열로 붙여줍니다. 그다음 `innerHTML`을 사용해서 화면에 태그로 넣어줍니다.

## 4. 친구 목록과 상세 페이지 연결하기

`02-routing1.html`과 `02-routing2-detail.html`에서는 지금까지 배운 내용을 하나로 연결했습니다.

1. 친구 객체들을 배열에 담습니다.
2. `JSON.stringify()`로 바꿔 localStorage에 저장합니다.
3. 다시 꺼낸 뒤 `JSON.parse()`로 배열을 복원합니다.
4. `map()`으로 친구 수만큼 링크를 만듭니다.
5. 주소에 친구의 `index`를 담아 상세 페이지로 이동합니다.
6. 상세 페이지에서 index에 해당하는 친구를 찾아 보여줍니다.

저장된 값이 없으면 `localStorage.getItem()`은 `null`을 돌려줍니다. 예제에서는 삼항 연산자로 `null`일 때 빈 배열인 `[]`을 사용하도록 처리했습니다.

## 5. event.target.value

`03-input-event.html`에서는 입력한 태그와 값을 이벤트 객체에서 꺼냈습니다.

```js
const 인풋검증기능 = (event) => {
  console.log(event.target)
  console.log(event.target.value)
}
```

- `event.target`: 지금 이벤트가 발생한 태그
- `event.target.value`: 그 태그에 입력하거나 선택한 값

같은 함수를 여러 input에서 사용해도 `event.target`을 이용하면 어떤 input에서 입력했는지 알 수 있습니다.

## 6. filter로 필요한 값만 골라내기

`03-filter.js`와 `03-select-event-filter.html`에서는 조건에 맞는 친구만 골라냈습니다.

```js
const 사과좋아하는친구들 = 친구들.filter(
  el => el.좋아하는과일 === "사과"
)
```

`filter()`는 배열의 값을 하나씩 검사하고, 조건이 참인 값만 모아서 **새로운 배열**을 만듭니다. 원본 배열은 그대로 유지됩니다.

`select`에서는 `onchange` 이벤트와 `event.target.value`를 사용해 선택한 과일을 확인하고, 그 값에 맞춰 친구 목록을 필터링했습니다.

## 오늘의 핵심

1. 조건에 따라 코드를 나눌 때 `if`, 삼항 연산자, `switch`를 사용합니다.
2. `map()`은 모든 값을 바꿔 새로운 배열을 만듭니다.
3. `filter()`는 조건에 맞는 값만 골라 새로운 배열을 만듭니다.
4. `join("")`은 문자열 배열을 하나의 문자열로 이어줍니다.
5. `event.target.value`로 입력하거나 선택한 값을 가져올 수 있습니다.
6. 배열의 index를 주소에 담으면 목록과 상세 페이지를 연결할 수 있습니다.
