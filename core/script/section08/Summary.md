# section08 오늘 배운 내용 정리

안녕하세요 여러분! 오늘은 데이터가 많을 때 일정한 개수로 나눠 보여주는 **페이지네이션**을 처음부터 끝까지 만들어봤습니다. 페이지 번호를 만들고, 이전·다음 묶음으로 이동하고, 선택한 페이지의 목록과 활성 버튼까지 연결했어요.

오늘 흐름은 이렇게 기억하면 좋아요.
**페이지 버튼 만들기 → 10개씩 묶어 이동하기 → 마지막 페이지 계산하기 → 현재 페이지의 목록만 보여주기 → 선택한 버튼 표시하기**

## 1. 페이지 번호 10개 만들기

`01-pagination-number.html`에서는 길이가 10인 배열을 만들고 `map()`으로 페이지 버튼 10개를 그렸습니다.

```js
const 철수상자 = new Array(10).fill("철수")

const 페이지들 = 철수상자.map((el, index) => `
  <button>${index + 1}</button>
`).join("")

document.getElementById("페이지보여주는곳").innerHTML = 페이지들
```

- `new Array(10)`: 길이가 10인 배열 만들기
- `.fill("철수")`: 비어 있는 10칸을 같은 값으로 채우기
- `map()`: 배열의 각 칸을 버튼 태그로 바꾸기
- `index + 1`: 0부터 시작하는 index를 1부터 시작하는 페이지 번호로 바꾸기
- `join("")`: 태그 배열을 하나의 문자열로 연결하기

배열 안의 `철수`라는 값이 중요한 것이 아니라, `map()`을 10번 실행할 수 있는 배열이 필요해서 채워준 거예요.

## 2. 시작페이지로 버튼 묶음 이동하기

`02-pagination-prev-next.html`에서는 현재 버튼 묶음의 첫 번호를 `시작페이지`에 저장했습니다.

```js
let 시작페이지 = 1

const 페이지버튼그리기 = () => {
  const 페이지들 = new Array(10).fill("철수").map((el, index) => `
    <button>${시작페이지 + index}</button>
  `).join("")

  document.getElementById("페이지보여주는곳").innerHTML = 페이지들
}
```

처음에는 `시작페이지`가 1이라서 1~10번이 만들어집니다. 다음 버튼을 누르면 시작페이지에 10을 더해 11~20번을 그리고, 이전 버튼을 누르면 10을 빼서 앞 묶음으로 돌아가요.

```js
const 이전페이지기능 = () => {
  시작페이지 = 시작페이지 - 10
  페이지버튼그리기()
}

const 다음페이지기능 = () => {
  시작페이지 = 시작페이지 + 10
  페이지버튼그리기()
}
```

변수의 값을 바꾼 뒤 그리기 함수를 다시 실행한다는 흐름이 중요합니다.

## 3. 마지막 페이지 계산하기

`03-pagination-last.html`에서는 전체 과일 개수를 이용해 마지막 페이지를 계산했습니다.

```js
const 마지막페이지 = Math.ceil(과일바구니.length / 10)
```

한 페이지에 데이터 10개를 보여준다면 전체 개수를 10으로 나누면 돼요. 데이터가 101개라면 10.1이 나오지만 마지막 1개도 별도의 페이지가 필요하므로 `Math.ceil()`로 올림해서 총 11페이지를 만듭니다.

```js
const 이전페이지기능 = () => {
  if (시작페이지 === 1) {
    alert("첫 페이지입니다.")
    return
  }

  시작페이지 = 시작페이지 - 10
  페이지버튼그리기()
}
```

```js
const 다음페이지기능 = () => {
  if (시작페이지 + 10 <= 마지막페이지) {
    시작페이지 = 시작페이지 + 10
    페이지버튼그리기()
  } else {
    alert("마지막 페이지입니다.")
  }
}
```

첫 묶음보다 앞으로 가지 않고, 마지막 페이지를 넘어서는 묶음도 만들지 않도록 조건문으로 막았습니다.

## 4. 마지막 묶음의 남는 버튼 숨기기

마지막 페이지가 11번이라면 두 번째 묶음에는 11번 버튼만 있어야 하고 12~20번은 보이면 안 됩니다.

```js
const 페이지들 = new Array(10).fill("철수").map((el, index) => {
  const 페이지번호 = 시작페이지 + index

  return 페이지번호 <= 마지막페이지
    ? `<button>${페이지번호}</button>`
    : ""
}).join("")
```

삼항 연산자로 계산한 페이지 번호가 마지막 페이지 이하일 때만 버튼을 만들고, 넘어가면 빈 문자열을 반환했어요.

## 5. 첫 페이지의 과일 목록 그리기

`04-pagination-list-1.html`에서는 과일 배열에서 처음 10개를 골라 화면에 보여줬습니다.

```js
const 과일목록그리기 = () => {
  const 과일목록 = 과일바구니.filter((el, index) => index <= 9)

  document.getElementById("과일보여주는곳").innerHTML =
    과일목록.map((과일) => `
      <div>${과일.name}는 ${과일.price}원 입니다.</div>
    `).join("")
}
```

- `filter()`: 현재 페이지에 필요한 데이터만 골라내기
- `map()`: 골라낸 데이터를 HTML 태그로 바꾸기
- `join("")`: 태그들을 하나의 문자열로 합치기

목록을 화면에 보여주려면 과일 객체 자체가 아니라 `name`, `price` 같은 필요한 값을 꺼내 HTML로 만들어야 해요.

## 6. 클릭한 페이지의 데이터 10개 계산하기

`05-pagination-list-all.html`에서는 클릭한 페이지 번호를 함수의 인자로 받아 해당 페이지의 과일만 골라냈습니다.

```js
const 과일목록그리기 = (클릭한페이지) => {
  const 과일목록 = 과일바구니.filter((el, index) => {
    const 건너뛸갯수 = (클릭한페이지 - 1) * 10
    const 건너뛸인덱스 = 건너뛸갯수 - 1

    return 건너뛸인덱스 < index &&
      index <= 건너뛸인덱스 + 10
  })
}
```

예를 들어 3페이지를 클릭했다면 다음처럼 계산돼요.

1. `(3 - 1) × 10 = 20`개를 건너뛰어요.
2. 배열 index 20부터 29까지 선택해요.
3. 화면에는 21번째부터 30번째 데이터가 보여요.

버튼을 만들 때 페이지 번호를 함수에 전달합니다.

```js
`<button onclick="과일목록그리기(${페이지번호})">
  ${페이지번호}
</button>`
```

이제 어떤 페이지 버튼을 눌렀는지 함수가 알 수 있고, 그 페이지에 맞는 목록을 다시 그릴 수 있어요.

참고로 같은 범위는 `slice()`를 이용하면 더 간단하게 표현할 수도 있습니다.

```js
const 시작인덱스 = (클릭한페이지 - 1) * 10
const 과일목록 = 과일바구니.slice(시작인덱스, 시작인덱스 + 10)
```

## 7. 이전·다음 버튼과 목록 함께 바꾸기

페이지 버튼 묶음만 바뀌고 과일 목록이 그대로 있으면 화면이 자연스럽지 않습니다. 그래서 이전·다음 버튼을 누를 때 두 가지 그리기 함수를 함께 실행했어요.

```js
시작페이지 = 시작페이지 + 10
과일목록그리기(시작페이지)
페이지버튼그리기()
```

- `과일목록그리기()`: 현재 페이지에 해당하는 데이터 표시
- `페이지버튼그리기()`: 현재 묶음의 페이지 번호 표시

상태가 바뀌면 그 상태를 사용하는 화면도 함께 다시 그려야 합니다.

## 8. 현재 선택한 페이지 버튼 표시하기

`06-pagination-active.html`에서는 클릭한 페이지 번호와 버튼의 페이지 번호를 비교해 활성 클래스를 적용했습니다.

```js
const 페이지버튼그리기 = (클릭한페이지) => {
  const 페이지들 = new Array(10).fill("철수").map((el, index) => {
    const 페이지번호 = 시작페이지 + index

    return 페이지번호 <= 마지막페이지 ? `
      <button
        onclick="
          과일목록그리기(${페이지번호});
          페이지버튼그리기(${페이지번호});
        "
        class="${클릭한페이지 === 페이지번호 ? "빨강색" : ""}"
      >
        ${페이지번호}
      </button>
    ` : ""
  }).join("")
}
```

```css
.빨강색 {
  color: white;
  background-color: red;
}
```

버튼을 클릭하면 목록뿐 아니라 페이지 버튼도 다시 그립니다. 이때 클릭한 번호와 각 버튼 번호가 같을 때만 `빨강색` 클래스를 넣어 현재 페이지가 무엇인지 보여줘요.

## 페이지네이션 전체 흐름

1. 전체 데이터 개수로 마지막 페이지를 계산해요.
2. `시작페이지`를 기준으로 페이지 버튼을 최대 10개 만들어요.
3. 클릭한 페이지 번호를 목록 그리기 함수에 전달해요.
4. `(페이지 - 1) × 페이지당 개수`로 시작 index를 계산해요.
5. 해당 범위의 데이터만 골라 HTML로 만들어요.
6. 클릭한 번호와 같은 버튼에 활성 클래스를 적용해요.
7. 이전·다음 버튼은 `시작페이지`를 10씩 변경하고 화면을 다시 그려요.

## 오늘의 핵심

1. `new Array(10).fill()`로 반복 실행에 사용할 10칸 배열을 만들 수 있어요.
2. `시작페이지 + index`로 현재 묶음의 페이지 번호를 계산해요.
3. 마지막 페이지는 `Math.ceil(전체 개수 / 페이지당 개수)`로 계산해요.
4. 마지막 페이지를 넘는 버튼은 조건문으로 만들지 않아요.
5. 클릭한 페이지에 따라 보여줄 데이터의 시작 index가 달라져요.
6. `filter()` 또는 `slice()`로 현재 페이지의 데이터만 골라낼 수 있어요.
7. 현재 페이지 번호를 비교해 활성 버튼의 클래스를 적용할 수 있어요.
