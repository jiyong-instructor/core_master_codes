

# 01-01 오늘 배운 내용 정리

안녕하세요 여러분! 오늘은 HTML로 화면의 뼈대를 만들고, CSS의 박스 모델을 이용해서 크기와 간격을 조절해봤습니다.

처음에는 속성이 많아 보여도 괜찮습니다. **박스의 안쪽 여백은 `padding`, 바깥쪽 여백은 `margin`**이라고 먼저 기억해두시면 됩니다!

## 1. HTML 기본 구조와 주요 태그

`hello.html`에서 제목, 문장, 이미지처럼 화면에 보이는 기본 태그뿐 아니라 시맨틱 태그도 함께 살펴봤습니다.

- `<h1>`, `<h2>`: 제목을 작성하는 태그
- `<p>`: 문장을 작성하는 태그
- `<div>`: 여러 내용을 하나의 영역으로 묶는 태그
- `<img>`: 이미지를 보여주는 태그
- `<a>`: 다른 페이지나 주소로 이동하는 링크 태그
- `<ul>`, `<ol>`, `<li>`: 목록을 만드는 태그
- `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`: 표를 만드는 태그
- `<form>`, `<input>`, `<label>`, `<textarea>`, `<button>`: 입력 폼을 만드는 태그

시맨틱 태그는 각 영역의 역할을 이름으로 알려줍니다.

- `<header>`: 머리말 영역
- `<nav>`: 이동 메뉴
- `<main>`: 핵심 내용
- `<section>`: 주제별 구역
- `<article>`: 독립적으로 읽을 수 있는 콘텐츠
- `<aside>`: 보조 정보
- `<footer>`: 맺음말 영역

## 2. HTML 속성 종류

속성은 태그에 추가 정보를 붙여주는 값입니다. 같은 태그라도 속성에 따라 동작이나 모양이 달라질 수 있습니다.

- 공통 속성: 대부분의 태그에 넣을 수 있는 속성입니다. 예: `id`, `class`, `style`, `title`
- 태그 전용 속성: 특정 태그에서만 주로 쓰는 속성입니다. 예: `href`, `src`, `alt`, `type`, `placeholder`
- 불리언 속성: 값 없이 써도 의미가 있는 속성입니다. 예: `checked`, `disabled`, `required`
- 데이터 속성: `data-`로 시작하는 사용자 정의 속성입니다. 예: `data-name`, `data-id`

자주 보는 속성 예시도 같이 기억해두면 좋습니다.

- `href`: 링크 주소
- `src`: 이미지나 파일 경로
- `alt`: 이미지를 설명하는 문장
- `lang`: 문서 언어
- `target`: 링크를 열 위치
- `rel`: 링크 관계 정보
- `placeholder`: 입력창 안내 문구

HTML은 화면의 구조를 만들고, CSS는 그 구조를 예쁘게 꾸며준다고 생각하시면 됩니다.

## 3. padding과 margin

`01-padding-and-margin.html`에서 박스의 간격을 조절해봤습니다.

```css
.박스1 {
  padding-top: 30px;
  padding-left: 30px;
}

.박스2 {
  margin-top: 30px;
  margin-left: 30px;
}
```

- `padding`: 테두리와 내용 사이의 **안쪽 여백**
- `margin`: 박스와 다른 요소 사이의 **바깥쪽 여백**

둘 다 공간을 만들지만 공간이 생기는 위치가 다릅니다. 개발자 도구에서 박스 모델을 직접 확인해보면 훨씬 쉽게 이해할 수 있습니다.

## 4. box-sizing

`02-box-sizing.html`에서는 박스의 실제 크기를 계산하는 방법을 배웠습니다.

```css
* {
  padding: 0;
  margin: 0;
  box-sizing: border-box;
}
```

기본값인 `content-box`는 `width`와 `height`에 padding과 border가 더해집니다. 반대로 `border-box`를 사용하면 padding과 border까지 지정한 크기 안에 포함됩니다.

그래서 실무에서는 모든 요소에 `box-sizing: border-box`를 적용해두고 시작하는 경우가 많습니다.

## 5. 마진 상쇄

`03-margin-collapsing.html`에서는 위아래로 만난 margin이 단순히 더해지지 않는 현상을 확인했습니다.

세로 방향의 margin이 만나면 두 값을 더하는 대신, 보통 더 큰 margin 하나만 적용됩니다. 예를 들어 `100px`과 `50px`이 만나면 간격이 `150px`이 아니라 `100px`처럼 보일 수 있습니다.

## 오늘의 핵심

1. HTML은 구조를 만들고, 시맨틱 태그는 각 영역의 역할을 더 분명하게 알려줍니다.
2. 속성은 태그에 추가 정보를 붙이는 값이며, 공통 속성과 전용 속성이 있습니다.
3. `padding`은 안쪽, `margin`은 바깥쪽 여백입니다.
4. `border-box`를 사용하면 박스 크기를 계산하기 편합니다.
5. 세로 margin은 서로 만났을 때 상쇄될 수 있습니다.
