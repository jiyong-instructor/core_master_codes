# 01-02 오늘 배운 내용 정리

안녕하세요 여러분! 오늘은 반복해서 사용할 코드를 함수로 묶는 방법과, 변수를 찾는 범위인 스코프를 배웠습니다. 그리고 호이스팅, TDZ, 화면이 모두 준비된 뒤 코드를 실행하는 방법까지 확인했습니다.

내용이 조금 많았지만 괜찮습니다. **함수는 코드를 담은 상자, 스코프는 변수를 사용할 수 있는 범위**라고 먼저 기억해주세요!

## 1. 함수와 return

`01-function-scope.html`에서 함수를 만들고 실행해봤습니다.

```js
function 더하기2(a, b) {
  const result = a + b
  return result
}

const 함수결과 = 더하기2(55, 45)
```

- 매개변수 `a`, `b`: 함수가 값을 전달받는 자리
- 인자 `55`, `45`: 함수를 실행할 때 실제로 전달하는 값
- `return`: 함수가 만든 결과를 함수 바깥으로 돌려주기

함수는 이름만 작성한다고 실행되지 않습니다. `더하기2(55, 45)`처럼 소괄호를 붙여 호출해야 합니다.

## 2. 스코프와 스코프 체인

`02-function-scope-chain.html`에서는 바깥 함수와 안쪽 함수가 각각 어떤 변수를 사용하는지 확인했습니다.

- 함수 안에서 만든 변수는 기본적으로 그 함수 안에서만 사용할 수 있습니다.
- 안쪽 함수는 자신의 바깥쪽에 있는 변수를 찾을 수 있습니다.
- 같은 이름의 변수가 안쪽에도 있다면 가장 가까운 변수를 먼저 사용합니다.

이렇게 현재 범위에서 시작해서 바깥 범위로 변수를 찾아가는 흐름을 **스코프 체인**이라고 합니다.

## 3. 호이스팅

`03-hoisting.html`에서는 선언보다 먼저 함수와 변수를 사용해봤습니다.

함수 선언식은 선언 전에 호출해도 실행될 수 있습니다. `var`도 선언 자체는 위로 끌어올려진 것처럼 동작하지만, 값이 할당되기 전에는 `undefined`가 나옵니다.

```js
console.log(내가만든변수) // undefined
var 내가만든변수 = "변수의 값"
```

코드가 실제로 위로 이동하는 것은 아니고, 자바스크립트가 실행 전에 선언을 먼저 처리하기 때문에 그렇게 보이는 것입니다.

## 4. TDZ와 함수 작성 방식

`04-hoisting-and-tdz.html`에서는 `var`, `let`, `const`의 차이와 여러 함수 작성 방식을 살펴봤습니다.

- 함수 선언식: `function 함수이름() {}`
- 함수 표현식: `const 함수이름 = function() {}`
- 화살표 함수: `const 함수이름 = () => {}`

`let`과 `const`도 선언은 미리 인식되지만, 선언문에 도착하기 전에는 사용할 수 없습니다. 이 구간을 TDZ(Temporal Dead Zone)라고 하며, 먼저 접근하면 오류가 발생합니다.

함수 표현식과 화살표 함수도 `const`에 담았다면 선언 전에 호출할 수 없습니다.

## 5. window.onload

`05-window-onload.html`에서는 HTML 화면이 모두 준비된 다음 DOM을 조작했습니다.

```js
window.onload = () => {
  const 내이름 = prompt("이름을 입력해주세요")
  document.getElementById("이름표시하는곳").innerText = 내이름
}
```

스크립트가 화면의 태그보다 먼저 실행되면 아직 태그를 찾지 못할 수 있습니다. `window.onload` 안에 작성하면 화면에 필요한 내용이 모두 로드된 뒤 실행됩니다.

## 오늘의 핵심

1. 함수는 반복해서 사용할 코드를 묶어둔 것입니다.
2. 매개변수로 값을 받고 `return`으로 결과를 돌려줄 수 있습니다.
3. 안쪽 스코프에서 같은 이름의 변수를 찾으면 가장 가까운 변수를 사용합니다.
4. `var`와 함수 선언식의 호이스팅 방식은 `let`, `const`와 다릅니다.
5. HTML 요소를 조작할 때는 그 요소가 먼저 만들어졌는지 확인해야 합니다.
