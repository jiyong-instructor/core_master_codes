1. 자주 쓰는 기본 태그

HTML은 화면의 뼈대를 만드는 언어입니다. 중요한 말은 이렇게 강조할 수 있습니다.

  • <h1>~<h6>: 제목 태그
  • <p>: 문단 태그
  • <span>: 문장 안의 작은 영역을 감싸는 태그
  • <div>: 여러 요소를 묶는 블록 태그
  • <br>: 줄바꿈
  • <hr>: 내용 구분선
  1. 제목을 먼저 작성합니다.
  2. 설명 문장을 덧붙입니다.
  3. 이미지와 링크를 추가합니다.

3. 같이 알아두면 좋은 태그

강조 태그, 코드 태그, 인용 태그도 자주 사용합니다.

HTML은 구조를 만들고 CSS는 스타일을 입힙니다.

<code>는 코드 문장을 보여줄 때, mark는 형광펜처럼 강조할 때 사용할 수 있습니다.

5. 시맨틱 태그 예제

  • <header>: 머리말 영역
  • <nav>: 이동 메뉴
  • <main>: 핵심 내용
  • <section>: 주제별 구역
  • <article>: 독립 콘텐츠
  • <aside>: 보조 정보
  • <footer>: 맺음말 영역

시맨틱 태그를 쓰면 사람이 읽기 쉽고, 검색 엔진과 보조 기술도 페이지 구조를 더 잘 이해할 수 있습니다.

이 예제는 HTML 태그를 눈으로 익히기 위한 연습용 페이지입니다.
